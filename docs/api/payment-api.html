支付 API — 三轮核验

支付验证

POST /api/payment/verify

请求体

{
  "orderId": "TH-20260809120000-ABC123",
  "courseId": "TH-1005",
  "amount": 45,
  "timestamp": 1754726400000,
  "signature": "a3f2b1c0d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0"
}

三轮核验流程

轮次校验内容失败原因
第1轮金额/课程ID/订单号格式/15分钟超时金额不匹配/订单号非法/超时
第2轮HMAC-SHA256 签名校验 + 订单去重签名失败/重放攻击
第3轮服务端幂等 + DB确认 + 线程锁订单已确认/处理中

响应

// 成功
{"ok": true, "round": 3, "redirectUrl": "https://..."}

// 失败
{"ok": false, "round": 2, "reason": "签名校验失败"}
⚠️ 每个订单号只能使用一次。重复提交将返回 round=3 错误。
