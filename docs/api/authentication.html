认证与签名

TechHub Pro v4.0 · 最后更新: 2026-08-09 · 作者: svcliny

认证与签名机制

所有支付相关 API 需要使用 HMAC-SHA256 签名认证。

签名算法

// 1. 构造 payload
String payload = orderId + "|" + courseId + "|" + amount + "|" + timestamp;

// 2. 使用 HMAC-SHA256 签名
Mac mac = Mac.getInstance("HmacSHA256");
SecretKeySpec key = new SecretKeySpec(HMAC_KEY.getBytes("UTF-8"), "HmacSHA256");
mac.init(key);
byte[] raw = mac.doFinal(payload.getBytes("UTF-8"));

// 3. 转十六进制
StringBuilder sig = new StringBuilder();
for (byte b : raw) sig.append(String.format("%02x", b));

请求头

Header值
X-Request-SignatureHMAC-SHA256 签名值
X-Request-TimestampUnix 毫秒时间戳
Content-Typeapplication/json

防重放窗口

签名有效期为 15 分钟。超过时间窗口的请求将被拒绝。
