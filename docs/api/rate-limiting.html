速率限制

为防止滥用，API 实施了速率限制策略。

端点类型限制窗口
公开 GET100 req/min滑动窗口
搜索30 req/min固定窗口
支付验证10 req/min固定窗口
静态资源不限-

超限响应

HTTP/1.1 429 Too Many Requests
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 60

{"error": "RATE_LIMITED", "retryAfter": 45}
