快速开始

TechHub Pro v4.0 · 最后更新: 2026-08-09 · 作者: svcliny

5分钟快速开始

1. 克隆仓库

git clone https://github.com/svcpower100510/svcpower-web.git
cd svcpower-web

2. 安装依赖

# Java 后端需要 sqlite-jdbc
wget -P lib/ https://github.com/xerial/sqlite-jdbc/releases/download/3.46.1.3/sqlite-jdbc-3.46.1.3.jar

3. 编译运行

chmod +x compile.sh run.sh
./compile.sh
./run.sh 8080

4. 测试 API

curl http://localhost:8080/api/health
curl http://localhost:8080/api/courses | jq
curl http://localhost:8080/api/search?q=python | jq

5. 前端部署

直接将 TechHub-Pro/ 目录推送到 GitHub，Cloudflare Pages 自动部署。

✅ 完成！你的网站已上线。
